# رحلة إلى قلبك ❤️ — ملاحظات هذه النسخة

## أهم التغييرات المعمارية

**الموبايل والـ Viewport**
- `100dvh` بدل `100vh` في `html/body/#app` — يحل مشكلة اختفاء المحتوى خلف شريط المتصفح.
- الـ canvas بيعيد حساب أبعاده عبر `ResizeObserver` + `orientationchange` بدل الاعتماد فقط على `resize`، فبيتصرف صح مع الدوران المفاجئ للهاتف.
- حجم العالم (`worldWidth/worldHeight`) بقى مرتبط بحجم الشاشة الفعلي بدل رقم ثابت كبير، فمفيش مساحات فاضية تُمشّي فيها اللاعب بدون سبب.

**حركة اللاعب**
- الحركة بقت بعجلة تسارع/تباطؤ حقيقية (`accel` + `friction`) بدل قفزة سرعة ثابتة، فحاسس إنه Character مش صورة بتتسحب.
- تأثير تهدئة مؤقت (`slowUntil`) لما اللاعب يلمس عائق خفيف (زي الريح في مرحلة المطر) بدل ما يخسر أو يتعطل تمامًا.

**الرسوميات**
- استبدلنا معظم الإيموجي بأشكال متجهية مرسومة بالـ Canvas (قلوب، نجوم، مظاريف رسائل، صندوق الهدية، يراعات) — عشان الشكل يبقى مصمّم خصيصًا مش "إيموجي جاهز".
- الشخصية نفسها بقت شكل متجهي بلمسات بسيطة (عين، خد، قلب صغير فوق الرأس) بدل إيموجي 💗 كبير.

**المراحل**
- كل مرحلة فيها عنصر أو اثنين *سرّيين* (قلب/نجمة/رسالة مخفية) بتظهر بس لما تقربي منها، مع إنجاز "Secret Finder" جديد.
- مرحلة المطر فيها منطقة "ريح" بسيطة بتبطّئك شوية (تحدي خفيف)، ومظلة تديكِ رسالة إضافية اختيارية.
- مرحلة الهدية بقت تتطلب جمع يراعتين ضوء الأول قبل ما صندوق الهدية يظهر أصلاً — استكشاف بدل الوصول المباشر.

**الأداء**
- تنضيف الـ event listeners والـ ResizeObserver عند إيقاف كل مرحلة (`stop()`) — مفيش تسريب ذاكرة.
- أنظمة الجزيئات بقت وضع واحد نشط في كل مرة (بتلات أو يراعات) بدل تراكمها.

## اختبار سريع قبل الرفع
1. افتحي `index.html` من سيرفر محلي (مش file:// عشان تحميل الخطوط والفيديو يشتغل صح).
2. جربي على عرض شاشة 360×800 و390×844 من أدوات المطوّر.
3. جربي تدوير الشاشة أثناء اللعب — الكاميرا والـ canvas المفروض يتصلحوا فورًا.
4. ادخلي كل مرحلة، اجمعي العناصر، جربي العنصر السرّي في كل مرحلة.
5. حطي ملفاتك الصوتية في `assets/audio/` والفيديو في `assets/video/birthday-video.mp4` بنفس الأسماء الموجودة في `js/audio.js` و`js/main.js`.
