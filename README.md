# رحلة إلى قلبك ❤️

لعبة ويب رومانسية تفاعلية بمناسبة عيد ميلاد حبيبتك — 5 مراحل قصصية تنتهي بفتح فيديو عيد ميلادها.

لا تحتاج أي Backend أو Build Process — فقط افتحي `index.html` أو ارفعي المجلد على GitHub Pages.

---

## 🚀 التشغيل السريع

1. افتحي ملف `index.html` مباشرة في أي متصفح (أو ارفعي المجلد كله على GitHub Pages).
2. للحصول على أفضل تجربة صوت/فيديو، شغّليها من خلال سيرفر محلي بسيط (اختياري):
   ```bash
   npx serve .
   # أو
   python3 -m http.server 8080
   ```

## 🌐 الرفع على GitHub Pages

1. أنشئي مستودع (repository) جديد وارفعي كل ملفات المجلد `birthday-game/` بداخله.
2. من إعدادات المستودع (Settings → Pages) اختاري الفرع `main` والمجلد `/root`.
3. بعد دقيقة أو اثنتين هيبقى عندك رابط اللعبة جاهز تبعتيه لحبيبتك 🎉.

---

## ✏️ أماكن التعديل المهمة

| هدفك | الملف | المكان بالضبط |
|---|---|---|
| اسم فيديو عيد الميلاد | `js/main.js` | `CONFIG.videoFile` أعلى الملف |
| الجملة الافتتاحية | `js/main.js` | `CONFIG.introLine` |
| رسائل حديقة الذكريات (نص + أيقونة + صورة) | `js/game.js` | مصفوفة `MEMORIES` |
| رسائل ليلة المطر | `js/game.js` | مصفوفة `RAIN_MESSAGES` |
| رسالة الأمنية (المرحلة ٤) | `js/game.js` | `WISH_RESULT_MESSAGE` |
| عدد القلوب المطلوب جمعها | `js/game.js` | `HEARTS_TARGET` |
| الرسالة النهائية عند الهدية | `index.html` | داخل `#gift-message` (قسم `screen-stage5`) |
| قائمة الإنجازات | `js/achievements.js` | كائن `LIST` |

### إضافة صورك
ضعي صورك داخل `assets/images/` ثم اكتبي المسار في حقل `image` لأي عنصر داخل `MEMORIES`، مثال:
```js
{ id: 'm2', icon: '📸', image: 'assets/images/our-photo.jpg', text: 'أول صورة سوا...' }
```

### إضافة الفيديو
ضعي ملف الفيديو باسم `birthday-video.mp4` داخل `assets/video/`
(أو غيّري الاسم من `CONFIG.videoFile` في `js/main.js` ليطابق اسم ملفك).

### إضافة الأصوات (اختياري)
ضعي الملفات التالية داخل `assets/audio/` بنفس الأسماء (أو غيّري الأسماء من `js/audio.js`):
- `background-music.mp3`
- `heart-collect.mp3`
- `button-click.mp3`
- `stage-complete.mp3`
- `achievement-unlock.mp3`
- `gift-open.mp3`
- `final-celebration.mp3`

> إذا لم تضيفي أي ملف صوتي، اللعبة هتشتغل بشكل طبيعي تمامًا بدون أي أخطاء.

## 🎮 المراحل

1. **جمع القلوب ❤️** — تحكم باللمس/الفأرة/الأسهم لجمع القلوب المتساقطة بفيزياء واقعية.
2. **حديقة الذكريات 🌹** — اكتشفي كل ذكرى مخبأة بالضغط عليها.
3. **ليلة المطر 🌧️** — تحركي وسط المطر لتقرئي رسائل رومانسية تدريجية.
4. **اصنعي أمنيتك ⭐** — اختاري نجمة لتتحول كل النجوم إلى قلب كبير.
5. **الهدية 🎁** — افتحي الصندوق لتظهر الرسالة الأخيرة وفيديو عيد الميلاد.

التقدم يُحفظ تلقائيًا (LocalStorage) — تقدر تقفلي المتصفح وترجعي من نفس المكان.
